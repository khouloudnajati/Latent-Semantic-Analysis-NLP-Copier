# Latent Semantic Analysis (LSA) for NLP

## Project Overview
This project explores Latent Semantic Analysis (LSA), a Natural Language Processing technique used to identify latent semantic relationships between words and documents.

## Objectives
- Preprocess and represent textual data.
- Build a document-term matrix using TF-IDF.
- Apply Singular Value Decomposition (SVD).
- Explore semantic relationships between documents and terms.
- Analyze the results of the LSA model.

## Technologies
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Scikit-learn
- NLP
- TF-IDF
- Singular Value Decomposition (SVD)
